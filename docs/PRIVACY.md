# 隐私与数据格式

## 不采集的内容

KeyStar 不保存：

- 用户实际输入的文本；
- 按键发生的先后顺序；
- 当前应用、窗口标题或进程名称；
- 鼠标坐标、移动轨迹或滚动距离；
- 手柄摇杆位置、摇杆幅度或扳机模拟量数值；
- 账号、设备身份或云端同步数据。

## 保存的内容

程序只保存一分钟内各物理按键、鼠标按键（左键、右键、中键和前/后侧键）、滚轮上下滚以及手柄按键的累计次数。手柄只记录按下次数，摇杆位置和扳机数值都不会被保存。界面中的十分钟统计由分钟数据派生。

数据位于程序旁的 `Data` 目录：

- `key-stats.db`：SQLite 聚合数据库；
- `settings.json`：本地设置。
- `archives\`：重置记录时归档的历史数据库，不会被程序删除。

程序使用 SQLite WAL，因此运行期间还可能出现 `key-stats.db-wal` 和 `key-stats.db-shm`。

## 迁移与删除

- 迁移：完整复制程序文件夹或 `Data` 目录；
- 删除全部记录：完整退出程序后删除 `Data` 目录；
- 卸载登录自启动：先在界面取消勾选，再删除程序文件夹。
